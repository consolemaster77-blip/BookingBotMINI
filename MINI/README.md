# Telegram-бот для записи — минимальная версия

Бот на **aiogram 3.x** для соло-специалиста: один мастер, одно расписание, запись за пару кликов.
Это упрощённая версия полнофункционального бота — без каталога специалистов, доп. опций,
CRM, тегов, промокодов и аналитики. Если вам нужны эти функции — вам нужна старшая версия,
не эта.

## Возможности

- Запись в 1-2 клика: бот сразу показывает ближайшее свободное время
- Мастер первичной настройки: рабочий бот за 4 шага
- Главный экран администратора — расписание на день
- Запись клиента администратором вручную (для тех, кто позвонил или пришёл без записи)
- Перенос и отмена записи клиентом (с указанием причины отмены)
- Отпуск и нерабочие периоды одним действием
- Онлайн-оплата и предоплата через Telegram Payments (опционально)
- Автоматические резервные копии базы данных

## Чем отличается от полной версии

Здесь нет: нескольких специалистов, доп. опций и кросс-продаж, CRM с тегами и рассылками,
промокодов, вопросов при записи, расширенной аналитики, дайджеста, healthcheck-эндпоинта.
Запись всегда подтверждается сразу — без ручного одобрения администратором.

## Требования

- Python 3.10+
- Токен Telegram-бота (получить у [@BotFather](https://t.me/BotFather))

## Установка

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен бота от @BotFather |
| `ADMIN_IDS` | да | Telegram ID администратора (можно несколько через запятую) |
| `DB_PATH` | нет | путь к файлу SQLite (по умолчанию `bot.db`) |
| `TIMEZONE` | нет | часовой пояс, например `Europe/Moscow` |
| `BACKUP_DIR`, `BACKUP_INTERVAL_HOURS`, `BACKUP_KEEP_COUNT` | нет | резервное копирование БД |
| `PAYMENT_PROVIDER_TOKEN` | нет | токен платёжного провайдера для приёма оплаты |

Узнать свой Telegram ID можно у [@userinfobot](https://t.me/userinfobot).

## Запуск

```bash
python main.py
```

При первом запуске бот сам создаёт базу данных. Затем отправьте боту `/admin` —
откроется мастер настройки из 4 шагов, после него бот уже принимает записи.

## Приём оплаты (опционально)

1. В [@BotFather](https://t.me/BotFather): ваш бот → Payments → выберите провайдера (ЮKassa и др.).
2. Токен впишите в `.env`: `PAYMENT_PROVIDER_TOKEN=...`, перезапустите бота.
3. В админ-панели: **⚙️ Настройки → 💳 Оплата** → включите.

## Структура проекта

```
main.py          точка входа
config.py        конфигурация: переменные окружения, часовой пояс
database.py      слой доступа к БД (aiosqlite), схема, миграции
keyboards.py     клавиатуры
handlers.py      все обработчики (клиент + админ) — один файл, чтобы код можно было прочитать целиком
scheduler.py     фоновые задачи (напоминания, бэкапы)
payments.py      оплата через Telegram Payments
backup.py        резервное копирование БД
tests/           автотесты (pytest)
```

## Тестирование

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## Команды бота

| Команда | Кто | Назначение |
|---|---|---|
| `/start` | все | приветствие и меню |
| `/admin` | администратор | панель администратора |
| `/cancel` | все | выход из любого текущего сценария |

## Рекомендации по деплою

- Запускайте как управляемый процесс (systemd/supervisor/Docker) с автоперезапуском.
- Файл `.env` не должен попадать в систему контроля версий.
- Резервные копии создаются автоматически (по умолчанию раз в 24 часа) и присылаются
  администратору документом в Telegram.
